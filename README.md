# 📺 YouTube Intelligence RAG Assistant
> Transform any YouTube video into an interactive, searchable knowledge base using Retrieval-Augmented Generation (RAG).
-----------------------------------------------------
## 🌟 Overview
Ever wanted to "talk" to a 2-hour long documentary or a technical lecture? This tool uses a **RAG pipeline** to ingest YouTube transcripts, index them in a vector database, and provide hyper-accurate, context-aware answers using the **Qwen3-235B** model.

### 🧠 The Tech Stack
* **Orchestration:** LangChain
* **LLM:** Qwen3-235B (via Hugging Face Endpoint)
* **Vector Store:** ChromaDB
* **Embeddings:** Hugging Face Transformers
* **Data Source:** YouTube Transcript API
